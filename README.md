# Photo Geolocator Agent

GitHub repository: `jajandurov-star/photo-geolocator-agent`

This agent takes street photos and returns precise latitude and longitude coordinates. It uses a vision-first approach via the make.fun metered gateway, backed by a robust statistical fallback prior.

## How to Run

Ensure dependencies are installed and run the main entry point via Node / Deno / your runner as configured in the workspace.
